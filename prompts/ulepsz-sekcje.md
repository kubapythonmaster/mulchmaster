# Prompt: mniej AI, więcej klientów (MulchMaster)

Ulepsz sekcje **Kontakt**, **FAQ**, **pas oferty (CTA)** i **Footer** strony MulchMaster (wycinka drzew / mulczowanie). Paleta: ciemna zieleń `#1b4332`, głęboka `#0c100e`, tła białe/jasne. Font: **Manrope**. Nie zmieniaj logiki formularza (składanie SMS/WhatsApp lokalnie).

## Cel
Wygląd lokalnej firmy usługowej, nie szablonu SaaS/AI. Sekcje mają **zachęcać do telefonu albo zdjęcia działki**.

## Zasady (twardo)
- Zero kart z miękkim cieniem, zaokrągleniami i „feature grid”
- Jedna hierarchia: **telefon → WhatsApp/Facebook → formularz**
- Copy krótkie, konkretne, po polsku — bez „kompleksowych rozwiązań” i pustych sloganów
- Layout **asymetryczny / editorial**, nie wyśrodkowany dashboard
- Mobile: ogromny klikalny numer, czytelne przyciski, bez ciasnych kolumn
- Zachowaj istniejące CSS variables i styl przycisków `.btn`

## Kontakt
- Lewa strona: kicker, nagłówek typu „Wyślij zdjęcie albo zadzwoń”, **ogromny numer**, krótki lead „jesteśmy w terenie — oddzwonimy”
- Szybkie kanały jako **lista z etykietą + krótkim powodem** (Telefon / WhatsApp / Facebook), nie rząd anonimowych buttonów
- Formularz po prawej jako jasny panel na ciemnym `tone`: nagłówek „Opisz działkę”, CTA „Złóż wiadomość” / mocniejsze „Przygotuj wiadomość”
- Jedna linia zaufania: oddzwaniamy, nic nie leci na serwer

## FAQ
- Nie center. Split: tytuł + 1 zdanie po lewej, lista po prawej (desktop)
- Numerowane pytania, mocny summary, czysty +/-
- Odpowiedzi krótkie, bez ściany tekstu

## Pas oferty (band-cta)
- Tekst **do lewej**, nie na środku
- Krótki lead, CTA „Zadzwoń” + „Wyślij zdjęcie działki”
- Cień zdjęcia czytelny, nie rozmycie całego kadru

## Footer
- Mocny telefon + jedno zdanie oferty
- Linki bez wyglądu „szablon WP”
- Kredyt Noctura zostaje

## Anti-wzorce
- Wyśrodkowane hero-CTA w każdej sekcji
- Identyczne karty 3×3
- Gradientowe buttony, glow, pill badges
- Angielskie mikrocopy
